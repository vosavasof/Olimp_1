# Онлайн лаборатория алгоритмов

## Запуск в интернете через GitHub

[Открыть создание Codespace](https://codespaces.new/vosavasof/Olimp_1?quickstart=1)

1. Войдите в свой GitHub и создайте Codespace. Дождитесь завершения настройки.
2. Сервер запускается автоматически. В выводе настройки/терминале появится личная HTTPS-ссылка учителя. Если вывод не виден, выполните в терминале `python3 Olimp_1/webapp/start_cloud.py` — повторный запуск покажет ту же ссылку.
3. На вкладке **Ports** у порта **8000** выберите **Port Visibility → Public**. Это откроет страницу входа через интернет. Персональные кабинеты требуют своей ссылки; ключ учителя не передавайте ученикам.
4. Откройте личную ссылку учителя, добавьте учеников и отправьте каждому его ссылку. Ученикам не нужен GitHub; сайт доступен через публичный HTTPS-порт.
5. На следующем занятии возобновляйте **тот же Codespace** на https://github.com/codespaces, а не создавайте новый.

Codespaces — облачная среда для проведения занятий, а не постоянный круглосуточный хостинг. При остановке или простое сайт перестаёт отвечать. Следите за лимитом времени/хранилища своего тарифа; доступность Codespaces зависит от аккаунта и политики организации. При необходимости увеличьте idle timeout в настройках Codespaces. Не используйте искусственный keepalive.

Ученики и результаты сохраняются в `Olimp_1/webapp/.cloud-state/classroom.sqlite3`, ключ учителя — в той же исключённой из Git папке. При удалении Codespace данные будут утрачены. Перед удалением остановите сервер и скачайте резервную копию базы. Не добавляйте базу и ключ в GitHub.

Если учитель открывает сайт через ссылку Ports без `#ключ`, потребуется ввести ключ. Повторный вызов start_cloud.py покажет личную ссылку с ключом. Все ученические ссылки создавайте через HTTPS-кабинет, а не через localhost.

В этой версии баллы интерактивных заданий вычисляются браузером; произвольный Python не исполняется и защищённая экзаменационная проверка не реализована. [Подробности школьного сервера](Olimp_1/webapp/README.md).

## Запуск в локальной сети

`python3 Olimp_1/webapp/server.py`

Python 3.10+, внешние зависимости не требуются.
