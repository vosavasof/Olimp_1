# Запуск без Cloudflare

`host.mjs` запускает тот же интерфейс и API на обычном Node.js 24. База SQLite и сессии хранятся на диске хостинга. Обращений к Cloudflare, D1 или GitHub при работе учеников нет. Зависимости npm для этого запуска не требуются.

1. Скопируйте исходники из GitHub и выполните `node build.mjs` в этой папке.
2. Сохраните свежую резервную копию `/api/backup` действующей лаборатории под правами учителя. Она содержит персональные ссылки; не добавляйте её в GitHub.
3. Создайте новую SQLite по `migrations/0001_initial.sql`, затем перенесите все строки восьми таблиц из копии с явным указанием колонок. В `app_meta.teacher_hash` сохраните SHA-256 прежнего ключа учителя. Проверьте каждое поле и количество строк. Сессии старого домена переносить не нужно.
4. Разместите базу в `private/classroom.sqlite3` с правами 600; каталог `private` — с правами 700. `host.mjs` обслуживает только каталог `public`, доступ к базе по URL закрыт.
5. В alwaysdata выберите сайт типа Node.js, версию 24 и команду `node /home/ACCOUNT/apps/olimp-lab/Olimp_1/cloudflare/host.mjs`. Задайте `PUBLIC_ORIGIN=https://ACCOUNT.alwaysdata.net` и `OLIMP_DB` с абсолютным путём к базе. Адрес и порт берутся из `IP`/`HOST` и `PORT`, выданных хостингом.
6. Включите HTTPS с перенаправлением HTTP. Проверьте вход прежним ключом, ученические ссылки на новом домене, журнал, обе роли одновременно и телефонный интерфейс. Доступ без VPN проверяйте из сети, в которой проходят занятия.

Перед окончательным переходом прекратите отправку ответов на старом домене и сделайте финальную копию. Сайты после переноса не синхронизируются автоматически. Не удаляйте исходную базу и резервные копии до завершения проверки.

Free предназначен для некоммерческого использования и ограничен квотами хостинга. Следите за уведомлениями об активности аккаунта и расходом места. Не включайте платные опции. Скачивайте резервные копии отдельно от хостинга.

Обновления устанавливайте с резервной копией действующей базы и без замены `private/classroom.sqlite3`. Таблица `entity_states` для архивов создаётся автоматически при первом API-запросе. Она включена в `/api/backup`; сохраняйте её вместе с остальными таблицами. После обновления исходников выполните `node build.mjs` и перезапустите сайт.
