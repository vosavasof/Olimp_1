# Постоянная лаборатория: Cloudflare Workers + D1

Эта версия сохраняет интерфейс лаборатории и переносит API и SQLite в Workers и D1. Компьютер учителя и Codespaces после публикации не нужны. Ученики открывают персональные ссылки без GitHub.

## Публикация

В Workers Builds выберите репозиторий, ветку `main`, корневую папку `Olimp_1/cloudflare`, команду сборки `node build.mjs` и команду публикации `npx wrangler deploy`. Требуется Node 22.12 или новее. Подключение D1 задано в `wrangler.jsonc`; для другого аккаунта замените UUID своей базы. Используйте бесплатные Workers и D1, не подключая платный план.

Для новой пустой базы выполните `migrations/0001_initial.sql` один раз. Настройте секрет `TEACHER_KEY` либо перенесите хеш прежнего ключа закрытым импортом. Не сохраняйте ключ в репозитории, переменных сборки или логах. При отсутствии обоих вариантов вход учителя закрыт.

## Перенос действующей базы

1. Сделайте согласованную резервную копию SQLite через `Connection.backup()`. Сохраните исходную базу и файл ключа.
2. На доверенном компьютере выполните `python3 export_sqlite.py snapshot.sqlite3 classroom.private.sql --teacher-key-file teacher.key`.
3. Импортируйте полученный SQL только в пустую D1 после создания схемы. Файл содержит персональные ссылки и ответы: он исключён из Git и не должен публиковаться.
4. Сверьте количество строк всех восьми таблиц, баллы и вход прежним ключом. Ученикам выдайте ссылки с новым доменом и прежним фрагментом после `#`.

Импорт не переносит браузерные сессии: потребуется повторный вход. Не применяйте импорт повторно. Не удаляйте прежнюю базу до сверки и завершения перехода. Ответы, добавленные в старой версии после снимка, сами не синхронизируются; на время окончательного переноса прекратите работу учеников в старом кабинете.

## Проверки и эксплуатация

`node build.mjs` собирает только общие материалы и интерфейс. База и ключи в сборку не входят. `test-worker.mjs` проверяет API на отдельной тестовой SQLite через Python 3; `preview.mjs` предназначен только для локальной проверки с вымышленными учениками.

Сессии хранятся в D1; cookies защищены HTTPS и HttpOnly. Журнал использует ревизии и загрузку изменений, чтобы сократить чтения. Бесплатные квоты Cloudflare ограничены: проверяйте расход в панели аккаунта. При исчерпании квоты сервис может временно отклонять запросы. Автоматические задания остаются учебной самопроверкой: результат проверки вычисляет клиент, это не защищённая экзаменационная система.

Учителю доступна резервная копия данных через авторизованный `/api/backup`; она содержит секретные персональные ссылки, храните её отдельно от GitHub. D1 Time Travel и экспорт базы доступны в панели Cloudflare в пределах условий текущего тарифа.
