# Онлайн лаборатория алгоритмов
Учебное веб-приложение по линейным алгоритмам обработки массивов для 9 класса. Зелёная адаптивная оболочка, кабинеты учителя и ученика, два варианта заданий, серверный журнал, проверка письменных работ учителем.

## Постоянное веб-приложение

Открыть лабораторию: https://olimp111.alwaysdata.net/

Кабинет учителя: https://olimp111.alwaysdata.net/teacher — вход прежним ключом. Ученикам выдавайте персональные ссылки из этого кабинета: у них новый домен, а перенесённые ключи сохранены. Приложение работает на alwaysdata с собственной SQLite независимо от компьютера учителя, Codespaces и Cloudflare. Подготовка, перенос и резервные копии описаны в [cloudflare/README.md](cloudflare/README.md). Бесплатный тариф alwaysdata имеет ограничения по ресурсам. Настройка запуска описана в [cloudflare/ALWAYSDATA.md](cloudflare/ALWAYSDATA.md).

## Локальный запуск
Python 3.10+, внешние зависимости не требуются:

```sh
python3 webapp/server.py
```

Для GitHub Codespaces из корня репозитория:

```sh
python3 Olimp_1/webapp/start_cloud.py
```

Подробности запуска, ключей и резервных копий: webapp/README.md. GitHub Pages не запускает Python-сервер. В Codespaces для доступа учеников без GitHub порт 8000 должен иметь видимость Public; после перезапуска проверьте её снова.

## Маршрут
В каждой из пяти тем:
1. Исследование массива.
2. Выбор правила.
3. Предсказание шага с объяснением.
4. Последовательная сборка всех строк программы.
5. Выбор проверочного теста.
6. Самостоятельное исправление ошибки.
7. Итоговая задача олимпиадного формата.
8–9. Дополнительные усложнения для сильных учеников.
Контрпример — отдельная необязательная углублённая практика.

Первой открывается теория без готового Python-кода. В каждой теме есть пункт «Теория и разбор», доступный заранее. Визуализация показывает список, переходы и значения переменных. Исходный код демонстрационной программы виден только учителю и никогда не появляется в интерфейсе ученика, в том числе после попытки. Теория редактируется учителем и доступна заранее, даже если выполнение задания ещё не выдано.

## Кабинеты
Учитель создаёт ученика и выдаёт ему личную ссылку. Ссылки новых учеников сохраняются и доступны для повторного копирования. В одной сессии браузера можно держать отдельные вкладки учителя и ученика; выход из одного кабинета не завершает другой.

В карточке ученика: имя, класс/группа, уровень подготовки, приватная заметка учителя, последний ответ, назначения и вариант. Правки сохраняются на сервере. Два варианта учитель видит в заранее загруженных панелях; можно переключаться без перезагрузки или открыть их рядом.

## Баллы и журнал
Для интерактивных заданий доступны две попытки: верная первая — 1 балл, верная вторая — 0,5, неверная — 0. После верного ответа дальнейшие попытки закрываются. Ограничение хранится на сервере и сохраняется после обновления страницы. Старые ответы и оценки не пересчитываются. Письменные программы, исправления и усложнённые задачи ожидают проверки учителя: до 5 баллов и комментарий. Учитель может вернуть работу с обязательным пояснением. Ученик получает уведомление внутри приложения, открывает прежний текст и отправляет исправленную версию. Для письменных работ правило двух автоматических попыток не применяется; повторная отправка открывается после возврата. Python ученика не выполняется сервером. Автоматические ответы не являются защищённой экзаменационной проверкой.

Журнал доступен только с верхней панели. Иерархия: ученик → баллы по темам → баллы каждого задания → ответ и обратная связь. Итог темы использует последнюю попытку каждого задания; повторы не суммируются. Основные задания №1–7 учитываются отдельно от дополнительных №8–9 и контрпримеров. Максимум для нового основного маршрута — 15 баллов на тему; старые автоматические оценки сохраняют исходную шкалу. Дополнительные баллы показаны отдельно. Невыполненное задание, нулевой результат и работа на проверке имеют разные подписи. В разделе всех ответов можно фильтровать попытки, оценивать код и скачивать журнал.

## Телефон
Телефонная версия оформлена как веб-приложение: компактная шапка и нижняя навигация, отдельный экран тем, постоянная панель отправки ответа, компактные результаты и формы. В конструкторе банк команд расположен на рабочем экране, а собранная программа открывается отдельной панелью. Длинные списки прокручиваются внутри задания, элементы для нажатия имеют ширину не меньше 44 px. Проверены размеры 320×568 и 390×844; горизонтальной прокрутки всей страницы нет. На компьютере сохраняется настольная компоновка. В меню учителя на телефоне выбирается один из двух вариантов; на компьютере их можно сравнивать рядом.

## Ограничения
Это учебный тренажёр с ручной проверкой Python, а не полноценный олимпиадный judge. Демо визуализирует базовую программу темы. Учительские заметки и данные учащихся хранятся в SQLite; базу, личные ссылки и ключи нельзя добавлять в Git. Перед обновлением или удалением Codespace сохраняйте резервную копию базы. Старые схемы SQLite обновляются добавлением колонок и таблиц, без удаления учеников и ответов.


### Разделы кабинета
Теория и пошаговая визуализация привязаны к каждой теме в содержании лаборатории; отдельной вкладки на верхней панели нет. Общая теория темы хранится в материале её первого задания; правки учителя сохраняются.
Вкладка «На проверке» показывает письменные работы, ожидающие оценки, с баллами и комментарием учителя.
«Классы и группы» позволяет включать ученика в несколько составов и назначать задания всей группе или выбранным участникам. Наборы по теме: №1–7 — основной маршрут, №1–9 — с усложнением; контрпример добавляется отдельно. По умолчанию новые задания добавляются к прежним, варианты учеников сохраняются. Режим замены меняет назначения, но не удаляет ответы и баллы.


### Правки по документу со скриншотами
В заданиях показаны конкретные учебные цели и число неверных ответов. Готовые программы и правильные значения удалены из обратной связи перед повторной попыткой.
В конструкторе программа и банк строк размещены в двух прокручиваемых областях; порядок банка сохраняется после выбора.
Практические списки различаются между заданиями и вариантами и не повторяют демонстрацию темы. Для письменных работ заданы входные данные и формат вывода, свой проверочный список редактируется и сохраняется вместе с ответом. Контрпримеры принимают не менее четырёх целых чисел без прежнего ограничения длины и диапазона −20…20 (используются точно представимые целые JavaScript).
Журнал учителя имеет карточный и табличный виды с фильтром класса/группы. Поиск скрыт у ученика. Личная анкета ученика доступна ему и учителю; она не меняет имя в списке класса, доступы и оценки.
Повторное нажатие на раздел возвращает страницу к началу без очистки введённого ответа. При загрузке файлов лаборатории передаётся роль сессии: ученик может работать без открытого кабинета учителя.

Проверка серверных сценариев без сети и реальных данных: `python3 tests/test_workflow.py`. Тест создаёт временную базу, проверяет попытки, возврат работы, уведомления, профиль и групповые назначения.


### Запуск с главного экрана
В меню приложения доступна команда «Добавить на главный экран». При поддержке браузером откроется установка; также можно использовать одноимённую команду меню браузера (на iPhone — меню «Поделиться»). Подготовлены manifest, значки 192/512 px и режим standalone. Адрес `/app` открывает действующий кабинет ученика или учителя по текущей сессии.

Телефонные стили вынесены в `phone.css`, оболочка кабинета — в `webapp/mobile-app.js`, управление экраном темы и панелью действий — в `mobile.js`. Мобильная компоновка также применяется на сенсорных телефонах в горизонтальном положении.

При наличии Node.js дополнительная проверка интерфейсного кода: `node tests/mobile_layout.cjs`. Она проверяет, что обновление подсказки не зацикливает наблюдатель DOM, а большие и отрицательные значения не растягивают столбики массива.

## Архив и доступ к заданиям

В списках учеников и групп доступны текущие, архивные и убранные записи. Архив и убранный список сохраняют журнал, баллы, назначения и состав групп; записи можно восстановить. Архивирование ученика закрывает его кабинет и завершает ученические сессии. Восстановление сохраняет персональную ссылку, но не отменяет отдельно отозванный ранее доступ. Архивирование группы не закрывает задания её ученикам.

Переключатели доступа у ученика и группы сохраняются сразу. Для группы видны состояния «Открыто всем», «Закрыто всем» и количество учеников с доступом. При выборе части группы статусы рассчитываются для выбранных получателей. Наборы №1–7, №1–9 и закрытие темы применяются к выбранным ученикам. Открытый ученический кабинет обновляет доступ автоматически, обычно за несколько секунд.
