# Онлайн лаборатория алгоритмов
Учебное веб-приложение по линейным алгоритмам обработки массивов для 9 класса. Зелёная адаптивная оболочка, кабинеты учителя и ученика, два варианта заданий, серверный журнал, проверка письменных работ учителем.

## Запуск
Python 3.10+, внешние зависимости не требуются:

```sh
python3 webapp/server.py
```

Для GitHub Codespaces из корня репозитория:

```sh
python3 Olimp_1/webapp/start_cloud.py
```

Подробности запуска, ключей и резервных копий: webapp/README.md. GitHub Pages не запускает Python-сервер. В Codespaces для доступа учеников без GitHub порт 8000 должен иметь видимость Public; после перезапуска проверьте её снова.

## Маршрут
В каждой из пяти тем:
1. Исследование массива.
2. Выбор правила.
3. Предсказание шага с объяснением.
4. Последовательная сборка всех строк программы.
5. Выбор проверочного теста.
6. Самостоятельное исправление ошибки.
7. Итоговая задача олимпиадного формата.
8–9. Дополнительные усложнения для сильных учеников.
Контрпример — отдельная необязательная углублённая практика.

Первой открывается теория без готового Python-кода. Визуальный разбор доступен в отдельной вкладке заранее; исходный код демонстрации ученику открывается после попытки, учителю — сразу. Теория редактируется учителем и доступна заранее, даже если выполнение задания ещё не выдано.

## Кабинеты
Учитель создаёт ученика и выдаёт ему личную ссылку. Ссылки новых учеников сохраняются и доступны для повторного копирования. В одной сессии браузера можно держать отдельные вкладки учителя и ученика; выход из одного кабинета не завершает другой.

В карточке ученика: имя, класс/группа, уровень подготовки, приватная заметка учителя, последний ответ, назначения и вариант. Правки сохраняются на сервере. Два варианта учитель видит в заранее загруженных панелях; можно переключаться без перезагрузки или открыть их рядом.

## Баллы и журнал
Интерактивный ответ получает 0 или 1 балл сразу. Письменные программы, исправления и усложнённые задачи ожидают проверки учителя: до 5 баллов и комментарий. Python ученика не выполняется сервером. Автоматические ответы не являются защищённой экзаменационной проверкой.

Журнал доступен только с верхней панели. Иерархия: ученик → баллы по темам → баллы каждого задания → ответ и обратная связь. Итог темы использует последнюю попытку каждого задания; повторы не суммируются. Основные задания №1–7 учитываются отдельно от дополнительных №8–9 и контрпримеров. Максимум для нового основного маршрута — 15 баллов на тему; старые автоматические оценки сохраняют исходную шкалу. Дополнительные баллы показаны отдельно. Невыполненное задание, нулевой результат и работа на проверке имеют разные подписи. В разделе всех ответов можно фильтровать попытки, оценивать код и скачивать журнал.

## Телефон
Проверены интерфейсы в браузере на ширине 390 px: страница и область задания не выходят за экран. Меню тем сворачивается, строки кода выбираются нажатием, перетаскивание необязательно, нет формата сборки из выпадающих списков. При сравнении вариантов на телефоне панели размещаются друг под другом.

## Ограничения
Это учебный тренажёр с ручной проверкой Python, а не полноценный олимпиадный judge. Демо визуализирует базовую программу темы. Учительские заметки и данные учащихся хранятся в SQLite; базу, личные ссылки и ключи нельзя добавлять в Git. Перед обновлением или удалением Codespace сохраняйте резервную копию базы. Старые схемы SQLite обновляются добавлением колонок и таблиц, без удаления учеников и ответов.


### Разделы кабинета
Теория и пошаговая визуализация вынесены в верхнюю вкладку «Теория и разбор».
Вкладка «На проверке» показывает письменные работы, ожидающие оценки, с баллами и комментарием учителя.
«Классы и группы» позволяет включать ученика в несколько составов и назначать задания всей группе или выбранным участникам. Наборы по теме: №1–7 — основной маршрут, №1–9 — с усложнением; контрпример добавляется отдельно. По умолчанию новые задания добавляются к прежним, варианты учеников сохраняются. Режим замены меняет назначения, но не удаляет ответы и баллы.
